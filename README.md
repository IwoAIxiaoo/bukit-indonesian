# Bukit 印尼语

用中文学印尼语的网页应用。一个文件就能用，不需要安装，也可以完全离线。

> Sedikit demi sedikit, lama-lama menjadi bukit.（积少成多，聚沙成山。）

## 里面有什么

- **31 课、801 个词、1602 个例句**：从问候、数字、吃饭、出行，到办公、工地、矿业、政策和读新闻。每个词有词性、中文释义、音标和至少 2 个例句，例句里目标词高亮。
- **发音**：全部内容都配了音频。397 个常用词是印尼人的真人录音，其中多数有 2–3 位说话人，可以和合成语音对比着听，选一个作为这个词的默认读音。其余是预先生成的合成语音。支持慢速和循环。
- **主动回忆式复习**：只看中文回想印尼语，再显示答案核对，然后选“认识 / 模糊 / 不认识”。认识的词间隔依次拉长（1、3、7、14、30 天……），模糊的保持原间隔，不认识的 10 分钟后再考。每复习 10 个词穿插一道选择题。
- **自由练习**：七种训练模式——单词卡、看词选义、看义选词、听音选义、拼写挑战、句子填空，以及 15 题限时 10 分钟的模拟挑战。可以选只练已学的词、某一课或全部课程。不计分、不设等级。
- **语法卡片**：41 组，学到相关单词时自动出现，左右滑动，不单独设语法课。
- **语法速查表**：26 张随时可查的总表，包括 me- 变化、-nya 和 di 的用法、词缀一览、代词、疑问词、数字换算等。
- **文化小贴士**：每课 1–2 条，共 62 条。
- **字母与发音页**：字母表、拼读规则、听辨练习。
- **学习记录**：每日学习量、连续天数、词汇增长曲线、热力图。

## 怎么用

**直接用**：到本仓库的 [Releases](../../releases) 下载 `bukit-offline.html`（约 50 MB，音频都在里面），用 Chrome 或 Edge 打开。学习进度保存在浏览器里，“设置”页可以复制备份和恢复。

**自己构建**（需要 Node.js 18 或更新版本，不需要安装任何依赖）：

```bash
node build.mjs
```

会生成两个文件：

| 文件 | 用途 |
|---|---|
| `bukit-offline.html` | 离线版。完整的独立网页，音频和字体都内嵌，不发任何网络请求。 |
| `bukit.html` | 在线版。作为 Claude Artifact 发布时使用：音频按课从 `audio/` 加载，进度同步到 claude.ai 账号，并提供 AI 例句、对话和逐词拆解。单独打开时这些联网功能不可用。 |

本地预览在线版：`python3 tools/serve.py`，然后打开 http://127.0.0.1:8765/bukit.html 。

## 目录

```
src/         课程内容和程序
  content-1.js … content-6.js   31 课的单词、例句、文化贴士
  grammar.js                    语法卡片
  ref.js                        语法速查表
  pron.js                       字母表、拼读规则、听辨词对
  ipa.js                        按拼写规则生成音标
  app.js, style.css, pre.js     页面逻辑和样式
audio/       按课打包的音频（每课一个 .mp3 和一个偏移表 .json）
fonts/       离线版内嵌的字体
tools/       音频生成管线和测试脚本，说明见 tools/README.md
build.mjs    构建脚本
```

想加词或改内容，改 `src/` 里对应的文件后重新构建即可。新加的印尼语文本需要另外生成音频，步骤见 [tools/README.md](tools/README.md)。

## 已知的限制

- 课程内容（释义、例句、语法说明、速查表）由 AI 编写，**没有经过印尼语母语者审校**，可能有不地道或不准确的地方。发现问题欢迎提 issue。
- 合成语音来自开源模型，个别很短的词（一两个音节的词、字母名）读得不够准。真人录音是从朗读的句子里自动切出来的，有的偏短或带底噪。
- 只在 Chrome 内核（Chrome、Edge）里测试过，没有在真机手机、Safari、Firefox 上测试。
- iPhone / iPad 的 Safari 不能直接打开本地网页文件，离线版在上面用不了。
- 离线版没有 AI 例句和跨设备同步。
