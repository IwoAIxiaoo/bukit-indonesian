# Bukit 印尼语

用中文学印尼语的网页应用。一个文件就能用，不需要安装，也可以完全离线。

> Sedikit demi sedikit, lama-lama menjadi bukit.（积少成多，聚沙成山。）

## 里面有什么

- **31 课、801 个词、1602 个例句**：从问候、数字、吃饭、出行，到办公、工地、矿业、政策和读新闻。每个词有词性、中文释义、音标和至少 2 个例句，例句里目标词高亮。
- **发音**：单词、例句和短文都配了音频。397 个常用词是印尼人的真人录音，其中多数有 2–3 位说话人，可以和合成语音对比着听，选一个作为这个词的默认读音。其余是预先生成的合成语音。支持慢速和循环。
- **学新词**：一组 8 个词，每看 2 个就马上回想一次，答错的并进下一次回想；看完一组再整组想一遍（能拼的词要拼出来），还是错的 10 分钟后再考。新学的词大约 3 小时后在复习里再出现一次，第二天再复习。
- **复习：句子挖空 + 自动评分 + FSRS**：给出挖掉目标词的真实短句和中文提示，直接打出印尼语（打口语说法也算对，比如 gak）。不用自己点“认识 / 模糊 / 不认识”，按答题表现自动评分：看了答案或错两次是 1 分，第二次才对、用了提示或扣除打字时间后想了超过 10 秒是 2 分，一次答对是 3 分，4 秒内答对是 4 分。下次什么时候复习由 [FSRS](https://github.com/open-spaced-repetition/ts-fsrs) 算法按评分来排；1 分的词明天再考，这一轮末尾也会再练一次。旧的学习记录会自动换算，不会丢。
- **今日学习**：首页一个按钮把当天的安排串起来——复习到期的词 → 学一组新词 → 默写今天学的词。没有内容的步骤自动跳过，中途可以退出，下次接着做。
- **自由练习**：十种训练模式——单词卡、看词选义、看义选词、听音选义、拼写挑战、跟打（照着打，逐字母标出对错）、听写（只听发音打出单词）、句子填空、易混辨析，以及 15 题限时 10 分钟的模拟挑战。可以选只练已学的词、错词本、收藏的词、某一课或全部课程。不计分、不设等级。
- **短文阅读**：24 篇分级短文（入门、生活、职场与矿业各 8 篇），有对话、通知、公文和仿写的行业短新闻。逐句配中文和音频，可以整篇连续播放、隐藏文字盲听；点句子里的任何一个词能查意思（会试着去掉 me-、di-、-nya 等词缀找到词根）；读完可以用这一篇做跟读和组句。
- **句子与语感**：用例句做四种练习——连续播放（一句接一句自动播，可设每句重复 1–3 遍）、影子跟读（播一句，留出差不多长的空档跟着说，可以隐藏文字只靠听）、连词成句（看中文排出印尼语）、听音组句（只听句子，从混有干扰词的词块里排出原句）。
- **错词本、收藏、已掌握**：复习评分在“模糊”以下、或练习里答错的词进错词本，复习时一次答对后移出；单词卡上可以收藏，也可以标成“已掌握”让它不再出现在复习里（可以取消）。
- **词条扩展**：每个词都有词根（`rootWord`，如 perbaikan → baik）、口语形式（`colloquial`，如 tidak → gak / nggak）和挖空短句（`clozeSentence`，带中文语境提示）。
- **语法卡片**：41 组，学到相关单词时自动出现，左右滑动，不单独设语法课。
- **易混词**：63 组容易混的词——拼写相近的（kakak/kakek、tahu/tahun）、同一类的（频率副词、时间词、方位词）、用法不同的（tahu/kenal、tidak/bukan、kami/kita）。单词卡上直接显示；学新词时遇到会插一张对比卡；选择题的干扰项优先用易混词；自由练习里有专门的“易混辨析”。
- **语法速查表**：29 张随时可查的总表，包括 me- 变化、-nya 和 di 的用法、词缀一览、代词、疑问词、数字换算，以及三张易混词总表。
- **文化小贴士**：每课 1–2 条，共 62 条。
- **字母与发音页**：字母表、拼读规则、听辨练习。
- **学习记录**：每日学习量、连续天数、词汇增长曲线、热力图。

## 怎么用

**直接用**：到本仓库的 [Releases](../../releases) 下载 `bukit-offline.html`（约 57 MB，音频都在里面），用 Chrome 或 Edge 打开。学习进度保存在浏览器里，“设置”页可以复制备份和恢复。

**自己构建**（需要 Node.js 18 或更新版本，不需要安装任何依赖）：

```bash
node build.mjs
```

会生成两个文件：

| 文件 | 用途 |
|---|---|
| `bukit-offline.html` | 离线版。完整的独立网页，音频和字体都内嵌，不发任何网络请求。 |
| `bukit.html` | 在线版。作为 Claude Artifact 发布时使用：音频按课从 `audio/` 加载，进度同步到 claude.ai 账号，并提供 AI 例句、对话和逐词拆解。单独打开时这些联网功能不可用。 |

本地预览在线版：`python3 tools/serve.py`，然后打开 http://127.0.0.1:8765/bukit.html 。

## 目录

```
src/         课程内容和程序
  content-1.js … content-6.js   31 课的单词、例句、文化贴士
  grammar.js                    语法卡片
  ref.js                        语法速查表
  reading.js                    短文阅读的 24 篇短文和生词表
  confuse.js                    易混词分组和区分说明
  pron.js                       字母表、拼读规则、听辨词对
  ipa.js                        按拼写规则生成音标
  lookup.js                     短文里点词查释义（去词缀找词根）
  lexicon.js                    词根、口语形式、挖空短句
  srs.js                        FSRS 排程和自动评分（evaluateAttempt）
vendor/      ts-fsrs（FSRS 算法库，MIT），构建时打进页面
  app.js, style.css, pre.js     页面逻辑和样式
audio/       按课打包的音频（每课一个 .mp3 和一个偏移表 .json）
fonts/       离线版内嵌的字体
tools/       音频生成管线和测试脚本，说明见 tools/README.md
build.mjs    构建脚本
```

想加词或改内容，改 `src/` 里对应的文件后重新构建即可。新加的印尼语文本需要另外生成音频，步骤见 [tools/README.md](tools/README.md)。

## 已知的限制

- 课程内容（释义、例句、语法说明、速查表、短文、易混词说明、词根和口语形式）由 AI 编写，**没有经过印尼语母语者审校**，可能有不地道或不准确的地方。发现问题欢迎提 issue。
- 合成语音来自开源模型，个别很短的词（一两个音节的词、字母名）读得不够准。真人录音是从朗读的句子里自动切出来的，有的偏短或带底噪。
- 只在 Chrome 内核（Chrome、Edge）里测试过，没有在真机手机、Safari、Firefox 上测试。
- iPhone / iPad 的 Safari 不能直接打开本地网页文件，离线版在上面用不了。
- 离线版没有 AI 例句和跨设备同步。
